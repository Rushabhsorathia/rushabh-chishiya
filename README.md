# chishiya.eventnetworks.xyz

Rushabh Sorathiya — personal about-me + Chishiya-flavored rules manifesto.

Live: https://chishiya.eventnetworks.xyz

## Stack
- React 18 + Vite 5
- Tailwind v3 (light mode, fully responsive)
- React Router 6
- Lucide icons

## Pages
- `/` — Home
- `/about` — About Rushabh
- `/journey` — Timeline
- `/projects` — Public projects
- `/chishiya` — The character
- `/rules` — The 18 rules
- `/contact` — Contact

## Local dev
```
npm install
npm run dev    # http://localhost:8107
npm run build
npm run preview
```
